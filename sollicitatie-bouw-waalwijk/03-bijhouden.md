# Bijhouden wie je gemaild hebt

Vul dit in terwijl je bezig bent. Zo weet je altijd waar je staat en
hoef je niks te onthouden.

| Bedrijf | Mail verstuurd op | Nabellen op (+7 dagen) | Gebeld? | Reactie | Status |

|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

## Wat zet je bij "Status"

- `verstuurd` - mail is weg, wachten
- `nabellen` - 7 dagen voorbij, moet ik bellen
- `gebeld` - gebeld, wachten op antwoord
- `gesprek` - ze willen met je praten
- `nee` - afwijzing, klaar, doorgaan
- `stil` - 3 weken niets en niet bereikbaar, klaar

## Tip
Zet elk belmoment in de agenda van je telefoon met een alarm.
Niet in je hoofd bewaren.
